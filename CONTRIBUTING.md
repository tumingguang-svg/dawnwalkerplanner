# Contributing

Unofficial fan project. Not affiliated with Rebel Wolves or Bandai Namco.

## Data (read this first)

Follow **[docs/DATA.md](docs/DATA.md)**. Short version:

- Do not state unverified values as fact.
- Pre-release numbers stay **Estimated**.
- Never invent **Verified** retail costs, endings, or missable lists.
- YouTube-derived data must include source URL, timestamp, platform, game version, and verification date.

## Copy and assets

- Original English commentary only.
- No official game art, logos, audio, or copyrighted assets.
- No cheats, trainers, or exploit instructions.
- Keep spoilers collapsed where the existing UI does that.
- Keep the unofficial fan disclaimer on content pages (`DataStatus` + site footer).

## Catalogs

Prefer an empty `/quests` or `/missables` table (or one clearly labeled schema example) over fake rows. Add real entries only with Estimated/Reported status and a source note.
